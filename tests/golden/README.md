# Golden Fixtures

This directory stores MATLAB-generated fixtures used for parity tests.

Generate them after MATLAB chunkIE is working locally:

```powershell
matlab -batch "run('scripts/matlab/generate_basic_fixtures.m')"
```

The Python runtime does not depend on MATLAB. Fixture data is not committed:
tests generate missing `.mat` files on demand by running the matching MATLAB
generator under `scripts/matlab`. If MATLAB setup or generation fails, the test
fails with the generator output.

Current fixture families:

- `lege_basic.mat` and `lege_extended.mat`: Legendre helper parity.
- `chunker_circle.mat`, `chunker_ops.mat`, and `geometry_core.mat`: basic
  chunking, chunker transforms/storage, and core geometry/domain/chunkgraph
  helpers.
- `kernel_pointinfo.mat`: point-kernel evaluators, MATLAB `@kernel` object
  algebra/factories, Green helpers, and biharmonic `bhgreen`-derived selectors.
- `operator_parity.mat`: dense/native, FMM, and FLAM operator paths.
- `quadggq.mat`: native quadrature, GGQ self/near/sparse special blocks, and
  adaptive close quadrature.
- `rcip.mat`: RCIP setup helpers, Schur updates, chunkgraph driver metadata,
  and recursive compression.
- `devtools_easy.mat`: focused MATLAB devtools slices.

For known MATLAB fixture inconsistencies, tests prefer component-wise references
over expected failures when the intended Python behavior is clear. Local fixture
files can be removed with:

```powershell
uv run python scripts/clean_test_data.py
```

`devtools_easy.mat` is generated by
`scripts/matlab/generate_devtools_easy_fixture.m`. It covers the compact
devtools parity track used by `tests/test_devtools_parity.py`, including
chunker/chunkgraph constructors, region and near-flag helpers, dense/adaptive
operator assembly, close-touching adaptive solve diagnostics,
Laplace and Helmholtz dense solve workflows, scalar matrix-free apply
diagnostics, singular PV/HS diagnostics, Green-identity target evaluation,
selected data-field/FLAM diagnostics, and direct
Stokes/elasticity/Helmholtz-1D diagnostics.

For manual inspection, `scripts/generate_devtools_easy_python_fixture.py`
generates `devtools_easy_python.npz` from the live Python package using the
same saved MATLAB inputs. The pytest suite still recomputes Python outputs live,
and the generated `.npz` is intentionally not tracked.

Runtime GGQ table data lives in `src/chunkie/data/quadggq` as packaged NumPy
assets. `geometry_core.mat` covers the implemented I GEOMETRY surface,
excluding `chunkerfit` and smoother workflows.
